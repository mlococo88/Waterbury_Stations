The track controls everything. Define the horizontal alignment (path in plan), the top-of-rail profile (elevation along the track), and superelevation (cant). Every platform and support elevation downstream is derived from these.

rail geometry

Left / right are relative to the direction of increasing station.

Superelevation

cant control points · linear runoff between rows

Cant in inches, positive = right rail higher than left rail looking up-station. Enter 0 on tangent. Values interpolate linearly between rows, so a spiral runoff is just two rows.

Horizontal Alignment

elements · stations and bearings computed from the POB

Curve + spirals is the usual railroad case: give the radius, the circular arc length and a spiral length at each end, and the transitions are built for you. Set a spiral length to 0 for a curve without one. Set which way the curve turns rather than using a negative radius. Curve only and Spiral only remain for anything that does not fit that pattern.

Top of Rail Profile

VPIs · first row is the start point, last is the end point

Interior rows carry a vertical curve length (0 = grade break). Type a grade to move the next VPI's elevation.

The platform edge is the control point: a horizontal setback from track centerline and a vertical offset above the rail. Everything on the platform surface is measured back from that edge at the cross slope.

Platform Profile

how the edge elevation runs longitudinally

Follow-the-rail rides every vertical curve exactly. An independent profile lets you set straight construction grades and then check the offset above the rail stays inside tolerance.

Curve Setback & Vehicle

car swing on curves

On the inside of a curve the mid-car swings in; on the outside the car ends swing out. The larger of the two governs on that side. Car body roll from superelevation is not modelled.

Support Lines

uniform layout · set the two end supports and how many in total

Shift supports moves the supports already in the table, keeping their names, grades and overrides. Generate supports rebuilds the table from the count — if the count is unchanged it also keeps names and overrides. Normal supports run radially from the track centerline, so on a curve the beam lengths along each beam line differ from the station spacing — the beam span table gives the built lengths.

bents · station, skew and optional overrides

Cap top override forces a value; leave blank to compute. Ground elevation is optional and only drives the exposure readout. Skew is degrees from normal, editable only when the normal-supports box above is cleared.
